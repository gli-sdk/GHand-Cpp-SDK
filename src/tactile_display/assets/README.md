# Tactile display assets

These six images are copied from `GHand-Python-SDK/src/ghand/tactile_display/assets`
to preserve the Python tactile display's appearance. See the source SDK's asset
manifest for their original GHand-GUI locations. GHand5 point coordinates and
overlay offsets also follow the Python display. All images are embedded with Qt
resources; the C++ display has no runtime dependency on either source repository.
